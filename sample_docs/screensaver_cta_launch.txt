Title: Screensaver CTA Launch Plan
Owner: Shibi Ayyanar
Subject: Screensaver CTA

The Screensaver CTA project adds a call-to-action rendering path for Fire TV screensaver ads.

Shibi Ayyanar implemented Screensaver CTA rendering and owns the integration between the Screensaver Experience service and the CTA Renderer.

Maya Chen reviewed the UX contract for CTA placement, focus behavior, and fallback rendering.

Daniel Park updated the ad decisioning integration so that eligible campaigns can return CTA metadata.

The primary repository for this work is firetv-screensaver-cta. The CTA Renderer depends on Ad Decisioning Gateway and Metrics Collector.

Launch readiness requires sign-off from Shibi Ayyanar for rendering, Daniel Park for ad decisioning, and Priya Raman for launch metrics.
